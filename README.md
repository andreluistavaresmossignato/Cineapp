### Descrição do Aplicativo
Sistema para favoritar filmes.

### Desafios Bônus Implementados
* Inclusão de novos campos no catálogo
* Remoção individual de itens favoritos
* Estilização personalizada de botões
* Contador de itens e estado vazio aprimorado

### Instruções para Execução
1. Execute o comando para instalar as dependências:
   ```bash
   npm install
   ```
2. Inicie o projeto com o comando abaixo (digite `yes` para instalar o ngrok caso solicitado):
   ```bash
   npx expo start --tunnel
   ```
